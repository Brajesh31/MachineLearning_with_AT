# Security Policy

## Scope

The current default branch is the maintained version of this educational repository.

## Reporting

Do not publish credentials, private data, or exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available.

## Safe usage

- Do not run example scripts with elevated privileges.
- Review file paths before running file-handling examples.
- Treat CSV files and other external inputs as untrusted data.
- Never commit passwords, API keys, tokens, or private datasets.
