# Learning path

This repository is organized as a practical sequence of Python and data-science examples.

## 1. Python fundamentals

Start in `Python_Programming/Python basics, Variables, Operators, Conditional Statements/`:

- `variables.py`: values and basic data types.
- `operators.py`: arithmetic, comparison, and logical operators.
- `conditional_statements.py`: if, elif, else, and nested conditions.

## 2. Collections and control flow

- `Lists and Strings/`: indexing, slicing, mutation, iteration, and comprehensions.
- `Dictionary, Tuple, Set/`: mapping, immutable sequences, uniqueness, and set operations.
- `For Loop, Break, and Continue statements/` and `Loops/`: iteration, nested loops, loop else, break, and continue.

## 3. Functions and object-oriented programming

- `Functions, Return Statement, Recursion/`: function calls, return values, recursion, factorial, and Fibonacci.
- `Object-Oriented Programming (OOP)/`: classes, encapsulation, inheritance, and polymorphism.
- `File Handling, Exception Handling/`: reading/writing files and handling common errors.

## 4. Data analysis

- `Data_Analysis/NumPy/`: arrays, vector operations, reshaping, diagonal, trace, and descriptive statistics.
- `Data_Analysis/Pandas/`: Series, DataFrames, slicing, CSV input/output, missing values, grouping, and concatenation.

## 5. Neural networks and generative AI

- `Neural_Network/neural_network.md`: introductory neural-network overview.
- `GenerativeAI/Fundamentals_notes.md`: introductory notes on LLMs, prompt injection, fine-tuning, governance, and production AI.

These notes are introductory. Verify fast-changing platform capabilities, model licenses, and regulatory statements against current primary documentation before relying on them.
