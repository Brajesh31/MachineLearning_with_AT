# Known limitations

- The repository is an introductory code collection, not a packaged Python library.
- Several original examples use hard-coded demonstration values by design.
- Interactive examples require a terminal and are not part of automated execution.
- The Generative AI notes are concise study notes, not a current reference for vendor features, legal interpretation, or model licensing.
- Neural-network documentation is introductory and does not include a training implementation.
- Some examples may need further adaptation before reuse with production data or large files.
